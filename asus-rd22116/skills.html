01 / CAPABILITIES

核心能力

以模型整合、Agent 架構、知識檢索與工程驗證能力，支撐 GenAI 應用從需求到可執行服務。

01.1

解決方案能力

LLM APPLICATION

LLM 應用與模型整合

從需求與資料結構出發，設計 Prompt、Structured Output、模型介面與批次資料流程，使 LLM 輸出能穩定進入後續系統與人工覆核環節。

AI AGENT

AI Agent 與工具流程

以 Function Calling、MCP、Webhook 與狀態管理組織 Agent 的工具使用及任務流轉，支援即時互動、非同步處理與人機協作。

GENAI PROTOTYPING

GenAI 技術評估與原型驗證

針對應用需求建立 baseline、評估條件與比較原型，判斷模型、檢索及工作流方案的可行性與系統整合成本。

RAG ENGINEERING

RAG 與知識檢索工程

整合文件索引、BM25／向量／圖譜檢索、Reranking 與來源追溯；並以 LightRAG 客製查詢 API、Graph Search 與 WebUI。
