01 / CAPABILITIES

核心能力

四項解決方案能力，以及八類可對應到專案的工程工具。

01.1

解決方案能力

LLM SOLUTION

結構化輸出與資料契約

把使用情境轉成 Schema 與更新規則；以 provider adapter、JSON 驗證／修復與批次處理，讓模型輸出可覆核、可持續更新。

AGENT WORKFLOW

工具呼叫與事件狀態

以 Function Calling 定義工具契約，串接 Realtime／WebRTC、Webhook 與任務狀態，讓流程可觀察、可追蹤、可續跑。

RESEARCH PROTOTYPE

技術調研與比較驗證

先定義問題、baseline 與測試條件，再以原型比較策略並記錄結果，把「可行」轉成可檢驗的工程證據。

RAG & LOCAL SERVICE

知識檢索與雲地模型接入

客製來源追溯與圖譜搜尋，並以 provider adapter 對接雲端或 Llama-compatible／Ollama 端點；已完成 LightRAG 原生 server／WebUI 的本機圖譜流程驗證。
