LLM／Agent 專案

02.1

代表案例

2025–2026｜企業合作

大型語言模型客戶輪廓分析系統

LLM SOLUTION

將分散於長篇客服與銷售對話中的需求、偏好及互動訊號，轉為具明確資料契約與持續更新機制的客戶輪廓。

FLOW　對話資料 → Schema 設計 → LLM 結構化擷取 → 驗證修復 → 增量更新與批次輸出

我的責任

負責 Persona 資料模型與後端資料流設計，建立結構化擷取、輸出驗證、異常修復、增量合併及批次輸出流程。

關鍵決策

以統一資料契約與 Provider Adapter 隔離模型供應商差異，使擷取、驗證與更新邏輯不依賴單一模型端點。

技術

Python、Prompt Engineering、JSON Schema、Provider Adapter、pandas。

工程驗證

完成單筆約 2 萬中文字的結構化擷取與輸出驗證，涵蓋解析、修復、增量合併及 JSON／Excel 交付流程。

2025｜研究型系統

會議諸葛｜Realtime Agent 與任務事件流程

AGENT WORKFLOW

建構即時會議 Agent 的語音脈絡、工具呼叫與任務狀態流程，使模型判斷能進一步驅動可保存、可追蹤的系統事件。

FLOW　語音脈絡 → Realtime Agent → Function Calling → Webhook／任務事件

我的責任

負責 Realtime Agent 與工具契約整合，串接 WebRTC、Function Calling、Webhook、會議資料及任務狀態。

關鍵決策

以結構化事件作為模型與應用系統的整合邊界，使即時互動、工具執行與會後任務共用一致狀態。

技術

TypeScript、React、Realtime／WebRTC、Function Calling、Webhook。

系統成果

整合即時逐字稿、工具呼叫、待辦、提醒與任務狀態，使會中事件能延續為會後可追蹤的工作項目。

2025–2026｜開源專案客製

LightRAG 可追溯知識問答服務

RAG / KNOWLEDGE GRAPH

基於 HKUDS／LightRAG 客製知識問答流程，整合多路檢索、知識圖譜與來源追溯，使回答能回傳實體、關係及原文片段。

FLOW　文件處理與索引 → 檢索（向量／圖譜／Hybrid） → 回答生成與來源追溯 → Graph Search

我的責任

負責查詢 API、來源追溯、Graph Search、檢索設定、繁中 WebUI 與本機服務環境的客製及整合。

關鍵決策

保留 upstream RAG 核心與 bindings，將客製範圍集中於來源追溯、檢索設定、查詢 API 與使用介面，保留後續升級路徑。

技術

Python、LightRAG、NetworkX、RESTful API、React、知識圖譜、檢索（向量／圖譜／Hybrid）。

實機驗證

完成本機 Server／WebUI 啟動、知識圖譜載入、節點關係呈現與查詢流程檢查；公開畫面使用 16 節點、18 關係的合成資料。
