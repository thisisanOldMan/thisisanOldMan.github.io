02.1

代表案例

2025–2026｜企業合作

大型語言模型客戶輪廓分析系統

LLM SOLUTION

將長篇客服與銷售對話，轉成可查詢、可覆核、可持續更新的客戶輪廓。

FLOW　對話 → Schema 擷取 → 驗證／修復 → 增量合併 → JSON／Excel

我的責任

設計 Persona Schema、模型輸出驗證與增量合併流程，完成 provider adapter、批次後端與輸出。

關鍵決策

以同一資料契約隔離模型差異，可接雲端 API 或 Llama-compatible／Ollama 地端端點。

技術

Python、Prompt／Schema、Provider Abstraction、JSON Repair、Pandas。

2025｜研究型系統

會議諸葛｜Realtime Agent 與任務事件流程

AGENT WORKFLOW

將即時會議語音脈絡，轉成可觸發、可保存、可追蹤的工具與任務事件。

FLOW　語音脈絡 → Realtime Agent → Function Calling → Webhook／任務事件

我的責任

整合 Realtime Agent 與工具 Schema，串接 WebRTC、Function Calling event、Webhook 與會議資料保存。

關鍵決策

把模型判斷轉成結構化事件，使會中互動與會後任務共用同一份狀態。

技術

TypeScript、React、Realtime／WebRTC、Function Calling、Webhook。

成果

完成即時逐字稿、工具事件、待辦、提醒與任務狀態的整合原型。

2025–2026｜開源專案客製

LightRAG 知識問答與模型端點整合

RAG + LOCAL

在 HKUDS／LightRAG 基礎上客製知識問答流程，讓回答帶回來源、實體、關係與原文片段。

FLOW　文件 → 實體／關係 → 混合檢索 → 回答＋來源 → Graph Search

我的責任

調整查詢 API、來源追溯、Graph Search、檢索設定、繁中介面與本機執行環境。

關鍵決策

沿用 upstream RAG 核心與 bindings，專注補齊可追溯輸出、使用介面與模型端點切換。

技術

Python、React、LightRAG、NetworkX、REST API、Llama-compatible endpoint。

實機驗證

本機啟動原生 server／WebUI，完成 16 節點、18 關係的圖譜載入與視覺化驗證。
