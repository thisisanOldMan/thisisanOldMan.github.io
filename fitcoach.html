PERSONAL PROJECT · LIVE PRODUCTION DEMO

FitCoach AI AI 健身教練

依健身程度與問題難度，自動分派入門、中階、進階專科教練；讓使用者從熱量計算、課表規劃到訓練紀錄，都能在同一套服務中完成。

以確定性流程守住數字、連結、授權與資料寫入；把語意理解、任務判斷與教練協作交給 Agent。

01

功能與服務

不是只有聊天介面，而是一套能理解問題、選擇教練、調用工具並完成健身任務的服務。

01

AI 教練對話

依程度與問題難度分派專科教練，提供符合當下需求的訓練與飲食建議。

02

熱量與飲食判定

以程式計算 TDEE 等精確數字，再由教練說明如何落實於日常飲食。

03

課表規劃

把目標、程度與時間條件轉為可執行課表，並保留修改與確認流程。

04

訓練紀錄

寫入前由使用者確認，避免誤記；以可靠交易保存每一次訓練成果。

05

動作與教學影片

查詢專業知識並嵌入對應教學影片，讓建議能直接連到下一步行動。

MULTI-AGENT ROUTING

任務、模型與教練協作

先以確定性條件處理明確任務，再由 LLM 補足語意判斷，最後以規則提供可靠 fallback；同時依難度選擇模型與專科教練。

MCP TOOL LAYER

自建與第三方工具可攜

自建 fitness-data MCP（stdio）並整合 YouTube MCP，將健身資料、教學影片與工具能力跨 Agent 共用。

LAYERED MEMORY

短期脈絡與長期偏好並存

以 LangGraph checkpointer 保存短期狀態與滾動摘要；Store 同時保存結構化資料與語意向量記憶。

SAFE WRITES

讓修改可確認、可重試

三層 Guardrail、Human-in-the-Loop、Idempotency、Transaction 與 session 身分檢查，共同保護資料寫入。

OBSERVABILITY

路由、工具、成本都有依據

追蹤模型、工具、cache 與成本；以可重跑 Evals 驗證關鍵情境，並設定全程成本預算。

RELIABILITY

可部署、可降級、可驗收

FastAPI、React 與 Docker 完成雲端服務，透過 fallback 與七題端到端情境驗證實際流程。

03
