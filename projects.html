02 / SELECTED WORK

LLM／Agent 專案

呈現我如何運用 LLM、AI Agent、RAG 與預測模型，解決企業資料整理、即時協作、知識查詢與風險預測問題。

02.1

核心專案

2025–2026｜企業合作

客戶輪廓分析系統

LLM SOLUTION

將長篇客服與銷售對話自動整理為可持續更新的客戶輪廓，讓客服與行銷人員快速掌握顧客需求、偏好與互動變化。

使用流程　匯入對話 → AI 擷取需求與偏好 → 驗證與更新 → 客戶輪廓／Excel

解決的問題

對話篇幅長且資訊分散，人工整理耗時，也難以隨新互動持續更新。

核心亮點

依固定欄位整理需求、偏好與互動紀錄；新對話加入後可自動更新，並檢查缺漏或格式錯誤。

實作成果

完成單筆約 2 萬中文字的擷取與驗證，並可批次輸出 JSON／Excel 客戶輪廓。

我的角色

設計客戶輪廓欄位與處理方式，完成對話擷取、結果檢查、輪廓更新與報表輸出。

Python · LLM 結構化輸出 · Persona Schema · JSON Schema · pandas

2025｜AI Agent 系統

即時會議 Agent

AGENT WORKFLOW

讓 AI 在會議中即時理解語音內容、建立待辦與提醒，並將會中決策延續為會後可追蹤的任務。

使用流程　即時語音會議 → AI 理解脈絡 → 建立待辦／提醒 → 會後任務追蹤

解決的問題

會議資訊、待辦與責任歸屬常散落於逐字稿和不同工具，會後容易漏接。

核心亮點

AI 可依會議脈絡使用工具、建立待辦與提醒，銜接會中互動與會後工作。

實作成果

將即時逐字稿、工具呼叫、待辦、提醒與任務進度集中於同一介面。

我的角色

規劃 AI 即時互動與任務功能，串接語音連線、工具呼叫、提醒與待辦資料。

TypeScript · React · Realtime API · WebRTC · Function Calling · Webhook

2025–2026｜開源專案客製

經發局知識問答系統

RAG / KNOWLEDGE GRAPH

將經發局文件整理成可查詢的知識服務，回答同時呈現關聯實體、知識脈絡與原文依據，方便快速核對來源。

使用流程　匯入文件 → 建立知識索引 → 查詢與檢索 → 回答附來源與關聯圖譜

解決的問題

文件量大且關聯分散，單純搜尋難以快速找到完整脈絡，也不易核對回答依據。

核心亮點

系統不只提供答案，也能顯示引用來源與概念之間的關係，方便追查答案依據。

實作成果

完成繁中操作介面、文件問答、來源追溯與知識圖譜瀏覽，並在本機完整運行。

我的角色

負責文件問答、來源追溯、圖譜查詢、繁中介面與本機部署。

Python · LightRAG · RESTful API · React · 向量檢索 · 知識圖譜
